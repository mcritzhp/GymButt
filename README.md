# GymButt

Website von [gymbutt.ch](https://gymbutt.ch). GymButt ist eine iPhone-App fürs Krafttraining mit einem Avatar, der mit jedem Training neue Items bekommt.

Die Seiten werden im Repo GymButt-docs unter `website/` gebaut (`python3 website/build.py`) und der Inhalt von `website/site/` hierher kopiert. Nicht direkt hier bearbeiten.
